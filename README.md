# LegalEase AI

Streamlit Community Cloud-ready legal information assistant.

## Run
`pip install -r requirements.txt`
`streamlit run app.py`

## Deploy
Push the folder to GitHub and select `app.py` in Streamlit Community Cloud.

The app validates the OpenAI API key/model when **Connect AI** is clicked and rejects non-legal questions before the main assistant answers.

This provides general legal information, not legal advice.
